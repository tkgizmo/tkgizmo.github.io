# Changelog

## v1.2.0

- Added a per-workspace "Apply Camera Pose" option to keep the current camera position when switching
- Reworked the Workspace Settings window into Workspaces / Rules / General tabs
- Workspaces can now be renamed and reordered from the Workspace Settings window; the order is reflected in the overlay dropdown
- Moved workspace Export / Import / Delete from the overlay dropdown into the Workspace Settings window

## v1.1.0

- Changed the data storage location to `UserSettings/`
- Added support for Unity 2022.3

## v1.0.0

- First release
