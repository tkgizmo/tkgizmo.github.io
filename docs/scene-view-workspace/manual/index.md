# Manual

Scene View Workspace saves your Scene View display and operation settings as **Workspaces** and switches between them in one click. You can instantly reproduce a Scene View set up for a specific task, such as UI work, modeling, lighting checks, or taking screenshots.

It can also switch Workspaces automatically, based on the target object, when you enter Isolation view.
