# Export / Import

Workspaces and Isolate auto-switch rules can each be exported to and imported from JSON files. Use this for backups or to share your setup between projects and teammates.

| What | Where |
| --- | --- |
| Workspaces | Workspace dropdown on the [overlay](./overlay) |
| Isolate auto-switch rules | [Workspace Settings window](./isolate-rules) |

## Workspaces

![Export and Import in the Workspace dropdown](/scene-view-workspace/SceneViewOverlay3.png)

- **Export** writes a single Workspace, or all Workspaces, to a JSON file.
- **Import...** loads a JSON file and restores the Workspaces as they were at export time.

## Isolate Auto-Switch Rules

![Export and Import buttons in the Workspace Settings window](/scene-view-workspace/SettingsWindow4.png)

- **Export...** saves the rules to a JSON file at any location.
- **Import...** loads a saved JSON file. You can choose to **append** to or **replace** the existing rules.
