# Saved Settings

A Workspace records the following Scene View states.

## Camera / View

- 2D / 3D mode, orthographic / perspective projection
- Pivot position, rotation, size (zoom), rotation lock
- FOV, Near / Far clip, Dynamic Clip, Occlusion Culling
- Camera movement speed (min / max / acceleration / easing)

## Rendering / Effects

- Draw mode (`DrawCameraMode`: Shaded / Wireframe / Overdraw, etc.)
- Scene Lighting, Scene Audio
- Fog / Skybox / Flares / Image Effects / Particle Systems / Visual Effect Graphs / Always Refresh

## Grid / Snap

- Grid display, grid snap, snap enabled/disabled

## Tools

- Current tool (Move / Rotate / Scale / Rect / View, etc.)
- Pivot mode (Center / Pivot), coordinate system (Global / Local)
- Tool handle display state, visible layer mask

## Gizmos

- Overall Gizmos display on/off
- 3D icons, icon size, Gizmo fade settings
- Selection outline / selection wire display
- Light Probe visualization settings
- Per-component Gizmo / icon enabled state
